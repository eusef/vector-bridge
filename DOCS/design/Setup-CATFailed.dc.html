    USB audio adapter found: IC-7300 USB Audio CODEC. It shares a USB device with the CP210x port.
  2. Radio control does not answer
    No reply from Icom IC-7300 on CP210x at 19200 baud after 3 tries.
    1. Check the radio is switched on.
    2. Check the USB or CI-V cable is in the radio, not an unpowered hub.
    3. Check the radio's CI-V baud rate (menu: CI-V Baud Rate) and that CI-V USB Echo is off.
    Serial port
    Only if you changed it on the radio. Copy it from the radio's menu (CI-V Address), for example 94.

    Find It for Me tries each common baud rate until the radio answers, up to 30 s. The remaining checks then run on by themselves.

    Details from Hamlib 
    rig_open: error = IO error

    rigctld's own last words. "Resource busy" means another program holds the port. "Permission denied" or "No such file" means the port picked above is wrong.
