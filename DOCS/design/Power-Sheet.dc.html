Maintenance mode
Field mode keeps the card read-only so pulling power is always safe. Maintenance mode makes it writable for updates, logs and kit edits.
Maintenance mode
Off. Field mode, safe to unplug.

Turning it on reboots the bridge into maintenance mode; this phone drops for about a minute. Refused while an app is streaming. Turn it off the same way before packing up.

While it is on
  1. An amber "Do not pull power" band shows on every page.
  2. Transmit stays as it is; receive keeps running.
  3. The bridge stays in it across restarts until you turn it off.
Restart
Restarts the audio and radio services without a reboot. Any app that is transmitting is unkeyed. Use it when a service is wedged; pulling power also works in field mode.
