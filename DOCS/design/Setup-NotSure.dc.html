Three questions. The answer suggests an interface and keying method.
1. How many USB cables run from the bridge to the radio side?
2. Is there a small box between the bridge and the radio?
3. What does the box say on it?
Looks like a SignaLink
A SignaLink carries audio and keys the radio when it hears a tone (VOX). The bridge cannot talk to the radio through it, so frequency and mode will not be shown and keying is set to VOX.

You still choose the radio model. If the radio also has its own USB port, plug that in too and the bridge can add radio control.
