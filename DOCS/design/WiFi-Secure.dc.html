Secure This Wi-Fi

First step. Takes one minute.
This Wi-Fi is open
VectorBridge-7C2A has no passphrase. Until it has one, settings cannot be saved and the bridge will not key the radio.
Keep it, or make it yours. 2 to 32 characters.
After you save
  1. The Wi-Fi restarts with the passphrase. This phone drops for about 20 s.
  2. Rejoin the Wi-Fi with the new passphrase and reopen vectorbridge.local or 10.42.0.1.
  3. The home page then offers Set Up a Radio.
Save and Secure Wi-Fi

Write the passphrase on the label under the bridge. If it is lost, put the card in a computer and edit wifi.txt on its first partition.
